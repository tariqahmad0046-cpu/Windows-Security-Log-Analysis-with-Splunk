# Splunk SPL Fundamentals & SOC Log Analysis Lab

## Project Overview

This project demonstrates practical learning and application of **Splunk Search Processing Language (SPL)** for Security Operations Center (SOC) log analysis.

The lab focuses on analyzing Windows security-related events, especially **Event ID 4688 (Process Creation)**, using SPL commands and functions commonly used during SOC investigations.

The objective of this project is to develop practical skills in:

* Log searching
* Event counting
* Host-based analysis
* EventCode analysis
* Filtering
* Field manipulation
* Conditional classification
* Frequency analysis
* Time-based analysis
* Basic security-event investigation

---

## Lab Environment

**SIEM:** Splunk

**Data Source:** Windows Event Logs

**Primary EventCode:** 4688 — Process Creation

**Platform:** Windows

**Query Language:** Splunk Search Processing Language (SPL)

# SPL Commands & Functions Practiced

## 1. Basic Index Search

```spl
index=main
```

Used to search events stored in the `main` index.

---

## 2. Count Total Events

```spl
index=main
| stats count
```

Used to determine the total number of events available in the selected search.

---

## 3. Host-wise Event Count

```spl
index=main
| stats count by host
```

Used to determine how many events were generated by each host.

---

## 4. EventCode Analysis

```spl
index=main EventCode=4688
| stats count by host
| sort - count
```

Used to analyze Process Creation events and identify hosts generating the highest number of events.

---

## 5. Latest Events

```spl
index=main EventCode=4688
| fields _time host EventCode
| sort - _time
| head 10
```

Used to retrieve the latest 10 process creation events.

---

## 6. Filtering with `where`

```spl
index=main EventCode=4688
| stats count by host
| where count > 50
```

Used to identify hosts generating more than 50 EventCode 4688 events.

---

## 7. Classification with `eval` and `if()`

```spl
index=main EventCode=4688
| stats count by host
| eval status=if(count > 50, "High", "Normal")
```

Used to classify hosts based on their event count.

---

## 8. Multi-level Classification with `case()`

```spl
index=main EventCode=4688
| stats count by host
| eval severity=case(
    count >= 100, "Critical",
    count >= 50, "High",
    count >= 20, "Medium",
    true(), "Low"
)
```

This demonstrates multi-condition classification using the `case()` function.

> Note: The severity thresholds in this lab are learning/demo thresholds and are not universal SOC severity standards.

---

## 9. Top Hosts

```spl
index=main EventCode=4688
| stats count by host
| top limit=5 host
```

Used to identify the five most frequently occurring hosts.

---

## 10. Rare Hosts

```spl
index=main EventCode=4688
| stats count by host
| rare limit=5 host
```

Used to identify hosts with comparatively low event frequency.

---

## 11. Time-based Analysis

```spl
index=main EventCode=4688
| timechart count
```

Used to visualize the number of process creation events over time.

Time-based analysis can help an analyst identify periods of increased or decreased activity.

---

## 12. Field Selection

```spl
index=main EventCode=4688
| fields _time host EventCode
```

Used to display only relevant fields and reduce unnecessary information in search results.

---

## 13. Field Summary

```spl
index=main EventCode=4688
| fieldsummary
```

Used to inspect available fields and their characteristics within the selected dataset.

# Example Investigation

### Scenario

A SOC analyst wants to investigate Windows Process Creation activity.

The analyst searches for:

```spl
index=main EventCode=4688
```

The events are then aggregated by host:

```spl
| stats count by host
```

The results are sorted:

```spl
| sort - count
```

The analyst can then classify activity:

```spl
| eval severity=case(
    count >= 100, "Critical",
    count >= 50, "High",
    count >= 20, "Medium",
    true(), "Low"
)
```

This creates a simple analytical view of process creation activity across hosts.
